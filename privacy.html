Privacy Policy

VL Reports · Last updated: November 8, 2026

VL Reports is a private reporting tool operated by Vadim Litvinenko ("we"). This policy explains what data the tool accesses and how it is used.

Data we access

With the user's explicit consent through Google OAuth (scope https://www.googleapis.com/auth/adwords) and Meta Login (permission ads_read), the tool reads advertising data of accounts the signed-in user already has access to: account names and IDs, campaign settings, and performance metrics such as spend, impressions, clicks and conversions. Access is read-only.

How we use it

The data is used only to prepare performance reports and optimization recommendations for the account owner and the clients whose accounts are managed. We do not sell, rent or share the data with third parties, and do not use it for advertising or profiling.

Storage and security

Access tokens are stored on a private server controlled by the operator, with access restricted to the operator, and are never published. Reports derived from the data are kept privately and only as long as they are useful for the work with the respective client.

Google API Services

The use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

You can revoke access at any time: for Google at myaccount.google.com/permissions, for Meta in Settings → Apps and Websites. On request we delete all stored data related to your accounts.
